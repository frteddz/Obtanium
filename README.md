# Obtanium

NeoForge mod for Minecraft 1.21.1.

Renames every Allthemodium Unobtainium item to Obtanium the moment it enters a player inventory. The rename sticks through chests, drops, trades and world reloads. Registry IDs are untouched.

Awards one random advancement out of a pool of 5 on first pickup of each item. No rerolls. The award is stored per player and survives death and reloads.

## Build

```
gradle assemble
```

Java 21, NeoForge 21.1.x, depends on Allthemodium 3.2.1.

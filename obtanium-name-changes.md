# Unobtainium to Obtanium Name Changes

_Updated for Allthemodium 3.2.1 (Minecraft 1.21.1)._

Replace `Unobtainium` with `Obtanium` in the item's displayed name **only after a player picks the item up and it enters their inventory**.

## Behavior

- Before a player picks up an item, its displayed name remains unchanged.
- When a player picks up an item from the list below, its displayed name changes from `Unobtainium` to `Obtanium`.
- The change persists for that item if it is moved into a chest, dropped, traded, or the world is reloaded.
- Items that have not been picked up by a player retain their original displayed names.
- Keep internal registry IDs unchanged to preserve recipes, saved worlds, and mod compatibility.
